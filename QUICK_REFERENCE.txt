🚀 QUICK START (30 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

  STEP 1: Deploy ExerciseDB (5 min)
  ────────────────────────────────
    Option A (Railway - Recommended):
      → https://railway.app
      → Deploy from GitHub: ExerciseDB/exercisedb-api
      → Copy your URL (e.g., https://your-app.up.railway.app)

    Option B (RapidAPI):
      → https://rapidapi.com/shetyjs/api/exercisedb
      → Free tier → Get API key

  STEP 2: Configure App (2 min)
  ────────────────────────────
    Edit .env.local:
      EXPO_PUBLIC_EXERCISEDB_URL=https://your-railway-url
    
    OR:
      EXPO_PUBLIC_EXERCISEDB_KEY=your_rapidapi_key

  STEP 3: Integrate Component (15 min)
  ──────────────────────────────────
    File: src/app/(tabs)/record/results.tsx
    
    Add import:
      import { ExerciseDetailCard } from '@/components/exercise-detail-card';
    
    Replace analysis display with:
      {analysis && (
        <ExerciseDetailCard
          exerciseName={analysis.exercise}
          aiScore={analysis.score}
          aiCritique={analysis.critique}
          keyCues={analysis.keyCues}
        />
      )}

  STEP 4: Test (5 min)
  ──────────────────
    → Record a video
    → See correct form GIF + AI analysis
    → Done! 🎉
